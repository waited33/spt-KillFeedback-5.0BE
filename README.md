
English
A kill-feedback HUD extracted from kmyuhkyuk's GamePanelHUD and made standalone: the GamePanelHUDCore and KmyTarkovApi dependencies are gone, so it runs as a self-contained BepInEx 6 (IL2CPP) plugin.
What it does in raid: on a kill, the left side types out [weapon][side] name [Lv.N][body part] while the right side shows the XP earned. Streaks add a Streak bonus [N] line, headshots add a headshot-bonus line, and the bottom-right corner keeps a running total for the raid.

中文
从 kmyuhkyuk 的 GamePanelHUD 中单独拆出的击杀反馈 HUD，去掉了 GamePanelHUDCore 与 KmyTarkovApi 依赖，做成可独立运行的 BepInEx 6（IL2CPP）插件。
游戏内效果：击杀后屏幕左侧逐字显示 [武器][阵营] 名字 [Lv.N][部位]，右侧显示本次获得的经验；连杀追加 连胜奖励 [N]，爆头追加一行爆头奖励，右下角累计本局总经验。
